# Daymark To-do List

A small React task manager with required name/description validation, inline task editing, completion tracking, deletion confirmation, and browser persistence through `localStorage`.

## Run locally

1. Install [Node.js](https://nodejs.org/) (version 20.19+ or 22.12+).
2. In this folder, install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL printed by Vite.

Use `npm run build` to create a production build and `npm run preview` to serve it locally.

Tasks are stored in this browser on this device. Clearing browser site data removes them; storage is not shared across browsers or devices.
